# 齋滋味採購詢價工作台

純靜態、本機儲存的詢價管理工具。公開網站與儲存庫**不含訂單、供應商名單、數量、估價、正式報價或聯絡資料**。

## 使用

1. 開啟 GitHub Pages 網站。
2. 選擇「匯入本機資料」，載入另外提供的 JSON 初始資料或自己的備份。
3. 點選商品填寫供應商報價、稅別、MOQ、運費、有效期限及售價，再按儲存。
4. 從供應商名錄整理聯絡資料，或製作可複製的詢價文字。
5. 定期匯出完整 JSON 備份。CSV 只作比較、不是可完整還原的備份。

## 資料保存與隱私

- 使用瀏覽器 localStorage，沒有後端資料庫、帳號登入、雲端同步或分析追蹤。
- JSON 檔案使用 File API 在本機解析，不會上傳。CSV、備份及詢價單均由瀏覽器產生。
- CSP 的 connect-src 'none' 禁止本頁以 fetch、XHR、WebSocket 等向外傳輸；form-action 'none' 禁止表單送出。
- 點擊供應商來源會開啟外部網站；不把輸入資料放入連結。Referrer Policy 設為 no-referrer。
- GitHub Pages 仍可能記錄一般網站存取資訊；本工具不送出使用者填寫的採購資料。
- 不同瀏覽器、不同電腦及不同網站來源不會自動同步。清除網站資料、無痕模式結束可能造成資料消失。
- 網站更新程式不會覆寫既有 localStorage；新版資料須自行匯入。匯入會取代資料，操作前請先備份。
- 本工具沒有多人共同編輯；請避免同時在多個分頁編輯，後儲存的版本可能覆寫前版。
- 本機備份可能包含商業資料，請勿提交至此公開儲存庫。

## 比價規則

含稅到貨單價 = 單位報價 × 稅額係數 + 本項分攤運費 ÷ 需求數量。

- 未稅5%係數1.05；含稅／零稅免稅係數1。僅是使用者所選計價方式，不代表判定稅務資格。
- 未填報價、稅別未確認、已過期、需求不足MOQ及非「已報價／已選定」不參與最低價比較。
- 運費未填暫按0元；MOQ及日期未填表示尚未記錄，請在下單前確認。
- 每箱數僅用於顯示進位箱數，不自動增購或增加採購總額。
- 商品差額不含貼標、出口作業、倉儲及其他間接成本，不是淨利。
- 公開販售紀錄不等於現貨、批發資格或可出口；同品牌不同規格僅是候選。

## 本機開啟與檢查

無需安裝依賴。下載後可直接用瀏覽器開啟 `dist/index.html`，或執行：

```sh
python -m http.server 8768 --directory dist
node --check dist/app.js
node tests.mjs
```

部署由 GitHub Actions 把 `dist` 發佈至 GitHub Pages，不執行使用者資料匯入。
